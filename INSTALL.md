# CapriMod — ручная установка в BONELAB (VR)

Мод **CapriMod** добавляет в BONELAB предмет **CHIP OF CAPRI** — чип с ИИ-конструктом
Капри (по мотивам «Cyberpunk: Edgerunners»). Всё содержимое (логика, модель чипа,
32 аудиозаписи озвучки) встроено в один DLL-файл — отдельных папок с ассетами ставить не нужно.

---

## Шаг 1. Установить MelonLoader (если ещё не установлен)

1. Скачайте **LemonLoader-Stable** (установщик MelonLoader):
   https://github.com/LemonLoaders-Maintained/LemonLoader-Stable/releases
   (файл `LemonLoader.Stable.Setup-x64.exe`)
2. Запустите установщик → выберите **BONELAB** (или укажите путь вручную).
3. Дождитесь окончания установки. В папке игры должны появиться:
   - `version.dll`
   - папка `MelonLoader\`
   - пустые папки `Mods\` и `Plugins\`

> Если Bonelab уже запускается через Steam/SteamCMD — устанавливайте MelonLoader
> именно в ту папку, где лежит `BONELAB.exe`
> (обычно `...\SteamLibrary\steamapps\common\Bonelab`).

## Шаг 2. Первый запуск игры

Запустите BONELAB **один раз через Steam** (нужно для генерации MelonLoader'ом
IL2CPP-сборок в `MelonLoader\Il2CppAssemblies\`). Убедитесь, что игра открылась
и в папке игры появился файл `Log.txt`. После этого игру можно закрыть.

## Шаг 3. Собрать мод (нужно сделать один раз)

Требуется: **.NET SDK 6.0+** (https://dotnet.microsoft.com/download/dotnet/6.0)
и папка игры.

```bat
:: Windows (cmd), из корня репозитория:
set BONELAB_DIR=C:\Program Files (x86)\Steam\steamapps\common\Bonelab
dotnet build src\CapriModPlugin\CapriMod.csproj -c Release
```

Готовый файл: `src\CapriModPlugin\bin\Release\net6.0\CapriMod.dll`
(при заданном `BONELAB_DIR` сборка автоматически копирует DLL в папку `Mods` игры).

Если собирать негде — скачайте `CapriMod.dll` из Releases этого репозитория.

## Шаг 4. Ручная установка мода

Скопируйте **`CapriMod.dll`** в:

```
<папка игры>\Mods\CapriMod.dll
```

Пример полного пути:
```
C:\Program Files (x86)\Steam\steamapps\common\Bonelab\Mods\CapriMod.dll
```

Всё. Никаких других файлов и папок добавлять не нужно — озвучка и модель чипа
вшиты внутрь DLL.

## Шаг 5. Запуск и проверка

1. Запустите BONELAB через Steam (VR-шлем подключён).
2. Откройте `Log.txt` в папке игры — должны быть строки:
   ```
   [CapriMod] CapriMod v1.0.0: Капри — конструкт из чипа...
   [CapriMod] VoiceBank: загружено 32 клипов
   [CapriMod] Bridge: создан предмет CHIP OF CAPRI возле игрока
   ```
3. В песочнице/уровне рядом с местом появления найдите светящийся бирюзовый
   кубик **CHIP OF CAPRI** (~9 см, подпись над ним).

## Как играть

| Действие | Управление |
|---|---|
| Взять чип | схватить рукой (Grip) |
| Надеть чип | поднести к голове — он «вставится» как имплант (слот головы) |
| Капри появляется | сама, в случайных местах уровня; **видна только вам** и говорит фразу |
| Телекинез | удерживайте **Grip** свободной руки — ближайший объект тянется к вам |
| Scorch (урон по времени удержания) | смотрите на врага/игрока и удерживайте **Trigger** — периодический урон растёт с длительностью |
| Снять чип | схватить чип у головы и потянуть |

Настройки (интервал появления, урон, дальность телекинеза) — в файле
`<папка игры>\UserData\CapriMod_config.json` (создаётся при первом запуске).

## Удаление

Удалите файл `<папка игры>\Mods\CapriMod.dll` (и, при желании,
`UserData\CapriMod_config.json`). Игра работает без мода как обычно.

## Частые проблемы

- **Мод не грузится** → проверьте, что стоит MelonLoader v5.7+/LemonLoader Stable
  и что BONELAB обновлён; откройте `Log.txt` ищите `[CapriMod]` / ошибки.
- **Не слышно озвучку** → убедитесь, что в логе `VoiceBank: загружено 32 клипов`;
  проверьте громкость VR-наушников.
- **Чип не виден** → он спавнится ~1 м справа-впереди от точки появления игрока;
  после каждой загрузки уровня создаётся заново.
- **Сборка выдаёт ошибки Reference** → `BONELAB_DIR` указан неверно: в этой папке
  должны быть `MelonLoader\Il2CppAssemblies\Assembly-CSharp.dll`.
